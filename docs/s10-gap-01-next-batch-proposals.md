# S10-GAP-01：下一批最小非重复候选

**以下各组均为 `PROPOSAL_NOT_AUTHORIZED`，本批没有执行。** 排序依现有 Odoo 业务风险与前置证据，不代表自动按序启动。原始断言和已采证据见[6+16覆盖矩阵](s10-gap-01-evidence-matrix.md)及[机器索引](evidence/s10-gap-01/coverage.json)。任何新批须另获用户同意和独立限定授权；#34 保持 OPEN、S10 技术及生产 BLOCKED、#35 S11 NOT_STARTED。

## P0：旧资金待办与日结可找回、可操作

- **业务目标与缺断言**：验证旧 `requested/approved/unknown` 退款和旧 `confirmed/unlocked` 日结在超过50退款/30日结后，当前有权角色仍能通过真实 Web 找到、按权限合法操作，且无权角色不能通过直接ID或附件/PDF越权。触及 F2/F3/F6、T05/T10/T11/T14/T16。R3已有55退款/55日结服务端分页，UI1只有少量记录的真实Web权限；两者之间的真实HTTP可操作性仍 `NOT_RUN`。
- **复用与最小操作建议**：先离线核对 R3 固定库记录与现行安装态 QWeb/服务合同是否可安全复用；若可，未来经授权仅从只读源克隆唯一隔离库，用有权/无权角色访问历史页与一条旧待办的合法状态动作，保留请求、响应、资金前后原生签名及分页游标。不可为凑阈值制造假收款、假退款或假日结。若无法安全复用现有真实合成历史，保持 `NOT_RUN` 并另报设计阻塞。
- **门禁/STOP**：仅一家合成库；锁定来源OID、提交、产品/安装态视图、账务和权限哈希；任何既有历史资金漂移、重复出款/贷项、跨店泄露、资金状态不明或Native signal11立即停止。退款执行与取消的幂等键及额度保护先核，不通过则不进行状态动作。验收要求旧目标真实HTTP可达、授权动作一次且原生账/审计与业务状态勾稽；无权访问真实拒绝。生产支付证据仍另行确认。

## P1：同源更正、日结时间边界与原版重印

- **业务目标与缺断言**：在一份已有真实临床/费库来源上，核对文字更正零经济变化、数量更正反向来源、实际退药隔离与未退不回库、600调620后按原600结算/原版重印；再检查合法实际时点但错业务日是否能绕已锁日结、补录双时间及普通人改删拒绝。触及 F3/F4、T07/T08/T11/T12/T15/T16。C/R3已分别验证部分模型事实，FC2已验特定关闭竞争，UI1已验三类指定PDF，W3已验真实Web费库；这里只补这些材料尚未共同证明的**同源前后不变量**。
- **复用与最小操作建议**：未来授权明确选一个只读合成来源，单库克隆后只执行缺失的合法更正/重印/错日期负向；不重做治疗600、检查80、4+2、740出账或500/240收款。保存原事件、价格版本、`stock.move`、invoice/partial、日结、审计及PDF原版字节的前后逐行签名。若既有库无法合法补录同源，不拼不同库结果，先判 `INSUFFICIENT_EVIDENCE`。
- **门禁/STOP**：按同一患者/店/法人、合成角色和已批准权限锁定；写动作须有唯一业务key与原状态前置，重复请求不生成第二贷项、库存move或PDF版本。已锁日不得靠改日期写入；任何原已过账单被覆盖、库存虚增、资金误退、审计改变或Native signal11立即停止。验收指标是更正/重印前后费库款签名符合各子断言、中文PDF字节与原版来源一致，真实Web/HTTP仅补缺失动作。生产税票/正式模板仍待确认。

## P2：跨法人原生交易的剩余失败与竞争边界

- **业务目标与缺断言**：针对 T09 已有同法人调拨及跨法人SO/PO、双方posted凭证和done收发正例，仅补异币种、批次效期不足、公司配置失败、同source双事务和原生posted中断后的原子回滚，确认公司/门店隔离。触及 T09，间接支撑 F4/T12 的来源完整性；不再重放无新增变量的合法正例。
- **复用与最小操作建议**：未来独立授权先静态核对现行产品支持的币种/税/法人配置；能构造合法合成前提才单库运行一组最小失败或竞争。只在授权明确时用两个独立事务后端和可审计屏障，读取双方订单、stock、account.move与S01审计；不能用离线Fake或source唯一约束代替原生失败后的全事务证明。
- **门禁/STOP**：同一隔离库、固定公司和合成批次，锁定两侧日记账/科目映射与幂等来源；预期失败必须无半张订单、半笔库存或半张posted凭证。任何原生不可恢复半单、越公司访问或Native signal11立即停止。异币种与生产税/科目政策未审定时标 `POLICY_PENDING`，不能自设生产配置来声称通过。
