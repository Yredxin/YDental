`terminalPending`只用于当前终态请求及其必要release；`needsReconcile`使本页保持待核对。它们不是服务器文书/接诊状态。所有实际持有、当前门店/公司/权限、版本与S06事务继续由既有后端验证。

响应后先核对 `generation` 和 JSON 内容快照，confirm/correct 的release后再次核对；程序直接改DOM但不触发input也不会被自动导航丢弃。真实原生控件在终态提交时不可编辑；浏览器保护不构成服务器权限，伪造请求仍受原后端限制。

交还已成功的提示明确为“交还已提交，不能在本页撤销”。恢复链接只含数值document_id，同源GET、新标签页、noopener/noreferrer，不含正文、token、lease或任意目的URL；原页保持可比较，不自动覆盖/丢弃本地文字。用户在新标签页核对实际状态后，保留或复制必要本地文字，再明确刷新原页并通过原合法编辑、待完善补记或附原因更正继续。不能以刷新/重新取得编辑承诺未同步内容已保存。

仍以 beforeunload 提醒带未同步/终态请求/待核对的离页；这不能替代明确核对出口。页面关闭、操作系统崩溃或用户明确丢弃本地文字不会自动写入服务器，本轮不引入离线病历存储或自动重放。
