## 7. 实际流程定义

**P1-F1 搜索到预览。**普通医生正常登录、选授权门店→从正常菜单进文书→输入姓名/业务号并搜索→从真实授权候选选择来源→选择实际模板或既有空值合成选项→明确点预览→仍显示现有预览结果与限制。到此结束，不点生成、不确认治疗。

**P1-F2 键盘与取消。**Tab定位来源选择器→展开→上下/Home/End移动候选→Esc退出确认值不变→再开并确认候选→Tab自然移到模板→选择→手动点击预览。键盘选项导航不发请求，原生业务参数不被可见标签替换。

**P1-F3 无结果、失效与权限。**检索无结果时明确说明；空来源不能提交假值。有源角色正常预览；无源/非法跨店参数由后端拒绝；撤权或门店revision失效按原边界处理，不能用客户端缓存继续显示/预览未授权来源。

**P1-F4 布局与未改区。**相同门店/过滤/视口比较前后，改变宽度/字号，弹层能完整操作；仅本区变暖色，列表/页头/生成区及其他页面内部样式和行为保持。来源/原件和固定财务库存投影不因查看改变。
