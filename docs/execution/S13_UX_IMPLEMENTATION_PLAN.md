### 3.1 展示与过滤

业务摘要→相关明细/来源→展开技术追溯。业务编号可含数字，URL/API关联键保留，每次请求重核权限，折叠不扩大读取范围。遵循英文源字符串与zh_CN，不改API key、枚举、公式、历史快照；按文书/财务/库存/加工/复诊领域翻译，不能所有done称治疗完成，不能sent称供应商发货或已收货。错误说明缺权/旧页/缺填/无结果/无适用选项且不泄露无权来源。

授权门店“全部”仅明示已授权范围；法人/门店关系后端校验，非法组合明确拒绝，不能静默缩小成假集团数。金额指标选币种，非金额不发送币种但后端仍拒非法参数；切换指标不遗留隐藏旧条件。期间、法人、门店、币种、状态、查询时点及各店时区/UTC边界可查看。页面/分页/CSV/钻取同一有效条件，返回保留上下文；合法数据变化显示查询时点并可刷新。

实收/实退按既有实际业务日。当前应收明确“当前应收（按所选账单日期范围）”及查询时点，日期只限定账单群，不冒历史as-of；批准待退、加工、复诊当前状态按字典。收款不是收入、贷项不是现金退款、不汇率折算或完整毛利。

患者按已授权姓名/业务号搜索，手机号仅原权限允许时；同名在权限内区分，无结果/分页可用。医生既有集团医疗历史用途不等于他店财务原单；仓库不因搜索取得全医疗加工统计；有结算权前台仍用同入口，不固定历史UID。自动补全不泄露更广人群/财务。

结算默认患者、本店账单、实收实退批准待退、原件摘要；进入办理显示对象/店/金额/渠道/状态/确认审批条件。关闭/取消不提交；重复或响应未知沿现请求幂等恢复，隐藏按钮不替后端校验。有权正例必须测。关闭复诊保历史/原因/责任，waiting等真实待办不假联系到货完成，不扩展新复诊能力。
