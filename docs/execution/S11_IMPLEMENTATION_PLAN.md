## 5. 取证与基线：服务于业务，不再成为独立无限任务

首次起点至少覆盖目标身份、权限/配置、已装模块、明确保护对象。后续按角色准备、关键业务提交、批次测试、升级和最终交付采对应状态；复用有效证据，不每个GET导出全库。

对同一业务链记录“意图→实际请求/动作→提交或回滚→独立读回”。响应未知先核提交，不盲重复；已确认提交的业务可继续其合法下一状态，不能为了补报告回头重演。防重/竞争可对明确用例执行预定请求，普通读操作可按回归需要复核，不把所有合法重复读取一律禁止。

新合成数据的正常副作用包括审计、会话、tracking、队列与状态变化。需用来源对象、实际操作及独立状态解释，不以表计数变化本身判全计划失败，也不以“正常可能发生”自动接受一切变化。新消息保留必要ID/关联及结果，不全表豁免；真实秘密、旧受限正文和无关隐私不收集。计数是辅助，不代替受保护行关键字段/关系核验。

源码、纯测试、MODEL、HTTP/RPC、浏览器、真实多连接和独立已提交状态分层记录。18项是用例定义，不是固定通过数；一次业务可支撑多个断言，但不得重复累计为不同测试。缺证据写缺证据，不能从源码可能性推成历史观察。

产品/工具执行候选与报告HEAD分开；只改文档保存差异即可。执行相关改变在新运行前复核影响，不制造“准入后写报告→HEAD变化→永远重新准入”的循环。本项目可自行管理的阶段配置和资源记录由主控按已授权范围维护，不伪造平台许可，不续旧S10窗口或抹掉历史计数。

### 8.2 连续执行期间的反馈

用户可随时问进度，主控也可在业务里程碑主动报告；报告不是请示，报告后继续已获准任务。下一项可在现有范围正常处理时，不以“下一步是……”结束整个任务等待确认。
