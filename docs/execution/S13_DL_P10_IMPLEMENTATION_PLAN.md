## 4. 允许/禁止的运行行为与示例流程

### F1 正常查询

普通有源读取权岗位 → 正常登录选店 → 原报表菜单 → 原单选/日期/门店/条件 → 明确查询 → 核页面显示的实际范围/时间/金额单位。正常中文/特殊字符按原方式安全显示，不改后台校验。

### F2 草拟条件与已生效结果

先形成合法结果 → 修改法人/日期/门店等但不点击Query → 确认旧结果及 export hidden/页码/来源链接保持 → 沿原来源链接查看 → 原返回URL仍对应原生效范围。浏览器返回可能受原生缓存恢复影响，不保证保留未提交草稿，不新增草稿持久化。再明确查询才改变生效范围。

### F3 指标切换

选中另一个授权指标 → 核只发生原3参数GET及原重置 → 检查非金额/无states时原字段确实不存在。源选择键盘、取消、点击外部等沿原P4具体规则，不把文书P1规则硬套过来。

### F4 读取型导出及钻取

本计划允许从既有入口实际 POST 导出CSV：仅既有合成数据、普通有源并有 export WRITE 的角色；不扩权、不外发。CSV是原数据的读取派生副本，不是新增业务原件，也不生成PDF。

至少核两种现有结构（例如一个金额指标、一个非金额计数指标）：文件头、实际生效过滤、总量、原11列、源集合/顺序/值和分币种单位，与同范围结果对应。不是比对“HTTP200”就通过，也不能拿前端草拟条件生成另一份CSV。

来源详情页与其分摊/返回正常只读验证，不改该页外观或行为；不得进入来源业务页执行收退款/库存。CSV留私有，效果包不包含整份CSV或原请求。

### F5 状态、范围与无结果

展开/收起时区和门店汇总，阅读当前时间、当地日期与口径。空结果不解释为无欠款/责任完成；非授权或非法输入按原后端拒绝，不以隐藏或过滤无权选项替代服务端检查。

不执行支付、退款、免单、日结、治疗、库存、接收/入库、组合扫码、文书生成/打印/签署/模板发布。正常认证、查询、钻取、导出和拒绝审计按实际分类；不能为了“零变化”关闭审计。
