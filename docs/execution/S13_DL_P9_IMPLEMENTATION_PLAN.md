## 2. 设计语言新增术语

总原则：组内紧、组间松、边缘有缓冲、展开不粘连；舒展但不稀疏。

|编号|术语|本项目定义|
|---|---|---|
|DL-21|层级化间距系统（Spacing system / tokens）|用少量命名尺度表达信息层级，而不是每个元素任意写一个边距。尺寸与布局复用规则，但不要求每处距离相同。|
|DL-22|内外间距分工（Inset / Stack / Gap）|padding管容器内衬，margin管独立块外缘，gap管同组兄弟项。按钮内衬与按钮之间的空隙是两回事。|
|DL-23|邻近性分组（Proximity grouping）|标签靠近自己的字段，字段/说明组成一组；不同任务组拉开，避免来源标签被看成上一行搜索的说明。|
|DL-24|垂直节奏（Vertical rhythm）|标题、说明、表单、动作、追溯正文和下一区域之间形成可重复的阅读节奏；不是固定整页行高或强迫所有内容塞进首屏。|
|DL-25|响应式安全留白（Responsive insets / gutters）|窄屏减小非必要外缘，保留控件之间和焦点周围的缓冲；用重排、换行而不是缩字或隐藏内容解决空间不足。|
|DL-26|密度平衡与单一间距归属（Density balance / spacing ownership）|同一空隙由一个明确规则负责，避免父gap、子margin和嵌套padding重复累加。长表保持适当密度，不把每一行扩成大卡片。|

这些编号是 YDental 的规范索引。留白/间距尺度、邻近关系属于设计方法；本文件给出的具体数值是项目执行约定。

### 2.1 基础尺度与具体映射

基础尺度：0 / .25rem / .5rem / .75rem / 1rem / 1.5rem / 2rem。
默认根字号16px时分别为 0 / 4 / 8 / 12 / 16 / 24 / 32px。不改全局根字号，浏览器字号增大后相对尺寸自然响应。4px只用于微调/细节，不用来分隔任务组。

|关系|本次默认约定|说明|
|---|---|---|
|标签 → 自己的输入/选择字段|`.5rem`（8px）|小于字段组之间的距离；原隐藏select不占布局。|
|同组相邻动作或并列字段|`.75rem`（12px）到`1rem`（16px）|动作组默认12px，表单行/列默认16px；窄屏仍至少12px，不靠文字空格。|
|搜索任务 → 来源/模板选择任务|`1.5rem`（24px）|在两实际可见任务边界之间计量，不把隐藏busy段当正常空白占位。|
|字段组 → 对应动作区|`1rem`（16px）|不把按钮贴在最后一个label上；按钮不变成新的业务表单。|
|标题 → 本区说明/首组内容|`.75rem`到`1rem`（12—16px）|已有合格值可保留；不要叠标题默认下边距和父gap。|
|summary → 展开的第一段正文/字段组|`.75rem`（12px）|仅展开后出现，不通过永久padding撑高所有关闭details。|
|同一追溯键 → 自己的值|`.25rem`到`.5rem`（4—8px）|键值不拆散；下一键值组使用12px左右的分隔，原键值/顺序不变。|
|独立页面模块/独立管理任务之间|`1.5rem`（24px）|必要重大区域可用2rem，必须说明；不是所有子块都加32px。|
|已有卡片内容 → 自己的边界|桌面`1.5rem`（24px），窄屏`1rem`（16px）|每层只设一次，不再层层套卡片；保留既有阅读最大宽度。|
|动作与相邻折叠/独立任务|`.75rem`到`1rem`（12—16px）|例如查看/下载组与打印折叠；焦点外轮廓不能被裁切或盖住。|

默认窄屏间距切换使用本页已有合适断点，原则上 45rem 附近从24px卡片内衬切16px；实际断点必须在映射表统一记录，不随控件任意增加断点。

本批不机械迁移已经验过的控件内部数值。P8按钮内衬.625em 1em、图文gap.5em、最小高度、圆角、色彩、焦点和busy spinner规则保持；P1控件内部padding/弹层/行高保持。表格既有单元格padding和列宽保持。新尺度主要管理它们外部的关系。

### 2.2 不接受的替代做法

不使用全局 `* { margin: ... }`、所有label/button/details统一外边距、空段落/连续br/空格撑距离、每处20px、固定高度卡片、justify-content:space-between强行撑满纵向空白、整页scale或隐藏溢出。

不为了留白删掉状态、权限或合成/待签提示；不把必读内容全部折叠。不为了“舒展”给每个表格行或每个句子套大卡片。无需让全部内容都在首屏显示，也不以“页面总高度增加多少”直接判通过。

## 3. 目标与精确范围

### 3.1 成功形态

普通医生从菜单进入同一文书主页面：一眼区分搜索与预览选择；标签属于哪个字段清楚；按钮和邻接任务有呼吸空间；追溯打开后内容不贴summary；预览下方版本选择和生成按钮不粘连；原件动作及页尾管理表单分组可读。颜色、文案、数据和业务操作仍为原有内容。

本批是一页的间距试点，不是整站页面架构改造。暂缓继续给报表/结算推广按钮，之后另起限定计划，不删除该后续方向。

### 3.2 可修改区域与边界

主要文件：`ydental_print/views/ydental_document_templates.xml` 中 `ydental_document_page`。同一模板会在 GET `/ydental/documents` 和 POST `/ydental/documents/action` 的预览结果中渲染，两者均须生效，不仅按GET路径门控。

|区域|允许的空间调整|冻结内容|
|---|---|---|
|页头与查询、原件区域的交界|本页模块外距、已有卡片内衬、标题与说明/导航组间距；合格部分保持|标题/提示文字、导航地址/组次、颜色字体和信息优先级|
|P1查询区|搜索section与preview表单间隔；标签/字段外部gap；字段组/按钮/说明间隔；错误和busy出现后的流式排布|两个combobox的JS、触发器内部/浮层内容与定位算法、字段/ID/ARIA/hidden/required/disabled、提交契约|
|已有预览区|标题/两追溯details/iframe外框/后续生成表单之间的距离；原label和按钮所在任务组的flow|iframe srcdoc/sandbox/height/width语义和内部正文、原版本选项/数据/生成参数；不改预览或PDF模板|
|原件列表所在区|标题/两说明/表格外框/分页的间距；每行查看下载动作组与打印details；trace展开正文的间隔|表格列定义/单元padding/原数据顺序/状态/全文hash/分页口径；不改按钮内衬和样式|
|操作结果和技术追溯|有结果时按组排布，summary与正文不贴；无结果时无占位|原t-if/result/status/pre与返回语义，不为了演示提交业务|
|模板管理与导出details|外部块间距；展开时summary→说明→表单→下一表单的节奏；本模板已有label/input的外部分组、按钮行gap|字段顺序/name/value/类型/选项/约束/审批含义/权限和表单提交；不美化系统下拉/新增JS|
|继承插入的临床集合、模拟设备失败、同意证据三块|**仅三个顶层details与邻接模块的外部间隔**，防止新空间关系仍与旧片段贴边|三个details内部的控件、文字、表格、表单、权限/接口一律不改，不给其内部套P9布局或P8按钮|

继承文件 `ydental_print/views/ydental_consent_templates.xml` 如需要，只允许给上述三个顶层details增加无业务含义的class/data标记来控制外距。不可包裹或移动它们，不改其中xpath定位逻辑。W0核实际合成视图和已安装扩展，不能仅看基模板而遗漏继承内容。

### 3.3 最小工程实现

- 新建局部 documents_spacing.scss（具体目录遵循仓库命名），在现有print资产中按真实原生顺序注册。用documents-spacing模板根标记加显式目标class约束；正文/按钮/控件共享样式不重构。
- 相对spacing token可集中在本页namespace；不改全局:root、.container、body/html、全部form/details/button，不改变P7/P8共享_actions.scss。当前先落一页，后续确需跨页复用时再机械提取。
- 支持增加无交互wrapper和给原容器加class；保持原form边界、label关联、字段DOM顺序、hidden与条件分支。不得嵌套form、复制桌面/移动两套表单、CSS order重排、把表单/label设display:contents来蒙混关系。
- 修改原spacing专属声明、删除同一目标的冲突margin/gap是允许的，但只限本计划明示位置；不能留两套互相竞争的规则后靠!important堆叠。
- 不对整个查询容器新增会让隐藏helper/portal占位的泛化grid。保持[hidden]、closed details与未渲染条件；busy/错误出现时可自然增高，不能预留无意义大洞，也不能覆盖其他内容。
- 页面.container现有最大宽度和全局边沟保持。本批“响应式留白”主要作用于已声明模块的内衬及间隙，不能顺带全面修正文书页根溢出、网站共用页头或继承表格。
- 间距引起目标区域纵向位移、输入可用宽度变化、自然换行是许可变化；不能再以“所有rect必须与P8字节相同”阻止这次改动。相反业务字段、语义、行为和非目标样式须保持。

## 6. 验收：P9-T01—12

每项记录实际候选、角色/条件、预期/实际、证据层级、独立结论。布局证据须同时有实际computed/box关系及原图；截图数量或任意“间距变大了”不是验收标准。

### T01 范围、合同与术语映射

diff限空间规则、必要marker/wrapper/资产、测试和文档。若改继承模板，仅三个顶层details无业务标记。映射原DOM与新DOM，去掉允许wrapper/标记后核原字段、form归属、label关联、顺序、条件、事件和全部提交契约。不得新增JS、修改接口或共享按钮token。

### T02 间距层级与单一归属

在正常16px根字号下，采一组桌面和一组窄屏：标签→字段8px；搜索任务→选择任务24px；字段组/按钮区16px；同行动作默认12px；展开正文12px；模块外距24px；已有卡片内衬24/16px。以明确layout box边界测量，不拿字形ink边界伪精确。允许亚像素舍入，默认误差不超过1 CSS px；映射表明确例外和已有保持项。不得父gap+子margin重复凑出双倍空白。

### T03 密度、展开与空状态

同一字段的标签明显属于该字段；不同任务之间间距更大。关闭details仅保留summary与正常外距，不为隐藏正文留空洞；预览/结果不存在不留下空卡片。错误/空源/真实busy出现后内容自然下移，不重叠、不隐藏说明。原件行仍为表格，不为留白增加固定最小行高、巨大空格或每行卡片。

### T04 五视口与长内容

1366×768、1440×900、768×1024、390×844、320×800核目标关系。长中文、说明、hash、label自然换行，首末全文可达；控件组换行后row-gap仍有效。目标范围无新增父级溢出或焦点裁切；旧表格保留局部横读，不隐藏列、缩字、复制DOM。
