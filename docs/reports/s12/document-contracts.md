# S12 文件与模板契约

当前为合成软件机制；正式正文、临床/财务政策、实际税务原件和物理设备仍待提供及审核。数据库中发布的合成模板只表示测试环境内走过审核状态，不构成正式启用。

|族|来源与状态|历史文件与用途|纸型|
|---|---|---|---|
|病历段/汇总|原生临床文书、作者/执行/确认事实及来源版本集合；草稿明确未完善；完整集合不静默过滤未确认来源|永久原件；完整/草稿/受政策允许的摘录分别表达|A4；80mm仅显式演示|
|知情同意材料|来源临床文书、门店和明确模板/政策版本；打印待签，上传待核验，受控核验另留人/时/结论|PDF不等于告知或签署；相同附件不能复用于另一个原件；旧版/另店不自动继承|A4；80mm演示不作正式纸型|
|内部账单|原生posted账单、确认费用、历史身份与价格来源|内部账单标题；不表示税票；当前目录变化不重算历史文件|A4|

|检查报告|实际检查来源/版本、作者/执行人与未做/部分/完成状态|不因生成文件推断检查执行|A4|

永久原件保存来源模型/ID/版本集合、身份/费用适用历史事实、模板ID/版本/审核状态/正文与SHA、生成实际人时、附件与PDF SHA、前版关系。来源事实SHA与加上生成戳的渲染事实SHA分别校验，不要求两者相等。

模板配置为纯文本，不接受可执行QWeb。模板按门店/族/版本唯一，走draft→reviewed→published；正式模板必须有审批引用，合成标识和适用范围冻结进原件。无发布模板的内建样式明确synthetic/unreviewed，不冒正式。

单份查看/下载/打印请求均重核当前源读取权；批量导出额外核导出权。附件、原生缩略图、直接报表/RPC和撤权旧页不能绕过源权限。原生图片路由允许返回不含原件的标准占位PNG，下载仍受源权限控制。

重印只读取保存的二进制并核SHA；原文件缺失明确失败。更正生成新的关联版本，不能替换或删除旧件。幂等恢复按actor/key、原参数/审核摘要和实际已保存文件核对；请求超时先查实际提交再恢复。生成/下载/打印不执行治疗、库存或收退款；打印请求成功只表示请求记录，不表示物理出纸。
