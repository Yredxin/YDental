# YD-DL-RWD-V2：三档响应式设计规范

本规范首先用于 S13 P14-V2 未付清账单，不自动改变其他页面。布局使用 CSS 视口像素，mobile-first、弹性布局与渐进增强；不依赖设备 DPR 或产品 JavaScript。

| 档位 | 布局视口 | P14 布局 |
| --- | --- | --- |
| S | 320 至 767.999 CSS px | 单列只读账单卡片和独立办理区 |
| M | 768 至 1279.999 CSS px | 五列原生表格和表外办理区 |
| L | 1280 CSS px 及以上 | 宽屏五列表格和双字段办理区 |

默认采用 S，仅新增 `min-width: 48rem`、`min-width: 80rem` 两条主要宽度媒体查询；媒体查询 rem 的参考值为浏览器初始字号。普通表单按可用空间 reflow，必要时表格单独二维滚动。小于 320 CSS px 标记 BELOW_MIN_DEGRADED，不隐藏关键金额或禁用合法业务。

建议局部 token：间距 0.5/0.75/1/1.5rem，圆角 0.625rem，控件最小高度 2.75rem，边框 1px；按钮内部使用 em，弹性宽度使用百分比、minmax 或 clamp。复用既有杏陶 `#94513a`、暖白 `#fffbf6`、纸面 `#fffefa`、正文 `#382f28`、边界 `#e5cdbd` 和焦点 `#6c513f`，不创建全局主题。禁止缩放变换、CSS zoom、固定缩小字体、根层裁切或禁止浏览器缩放。

S 面板 padding 与卡片 gap 为 0.75rem，主按钮占办理容器宽度；M 面板 padding 和主要组间距为 1rem，字段随空间自适应；L 面板 padding 为 1.5rem、区域 gap 1.25–1.5rem、字段两列、操作独立一行。容器明确承担间距，避免父子重复堆叠。

## P14 结构和验收

| 对象 | S | M/L | 全档共同要求 |
| --- | --- | --- | --- |
| 账单阅读 | 单列卡片 | 原生五列表及表头 | 原生单号、业务日、原金额、余额、内部账单信息均可读；同一来源，不重复 ID |
| 办理 | 每笔独立面板 | 表格外每笔独立面板 | 单号和余额明确；唯一可提交表单及 PDF 入口位于横滚容器外 |
| 字段及操作 | 免单额、原因、确认、取消单列 | M 自适应；L 双字段加操作行 | 原字段、验证、权限、令牌、URL、details 同名组和分页不变 |
| 键盘 | 自然页面滚动 | 表格可局部滚动 | Tab/Shift+Tab 后整个焦点轮廓可见；Enter/Space 和真正 JS-off 可用 |

互斥只读视图使用 `display: none` 隐藏非当前视图，隐藏项不进入键盘序列；不在表格滚动区放置新可聚焦办理锚点。每笔账单仅一份 waive 表单，且不复制业务状态。不得将屏幕阅读顺序、表格语义或焦点完整性降级为局部可见。

技术验收使用真实岗位及完整加载资源，在 Chromium 和 WebKit 覆盖规定边界、缩放和真正 JS-off；截图、CSS、键盘顺序和几何必须互相印证。合成 HTML 不代替真实页面，历史失败不追溯改写。
