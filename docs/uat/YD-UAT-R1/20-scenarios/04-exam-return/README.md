# 治疗—检查—返回或交还

当前准备：**ENVIRONMENT_NOT_READY**。本页是流程导航；所有用户用例初始 NOT_RUN，用户结果只填写在各功能用例中。

**逻辑对象：** `SC04-EXEC-A`、`SC04-EXAM-A`（交还/完成对照另用 `SC07-EXEC-A/B`）。这些是未来分配的逻辑编号，并非数据库 ID；先按[合成对象映射](../../00-guide/scenario-data-map.md)由负责人核验实际对应与状态，再按[唯一执行清单](../../00-guide/execution-checklist.md)执行或接续。结果记录在唯一原始用例对应 RUN-ID；同一来源已执行动作只引用原记录，不重复提交。

**目的与价值：** 验证外部检查任务和医疗接诊的保留返回，不把检查结束当作治疗结束。
**参与岗位与交接：** [治疗医生](../../10-roles/treatment-doctor/README.md) → [前台](../../10-roles/front-desk/README.md) → [检查医生](../../10-roles/exam-doctor/README.md)。箭头表示主要协作，并非授权或严格身份切换；各步骤以其岗位为准。
**前置准备：** 新合成医疗任务已开始并保存文书；医疗原持有人、有效检查服务、合成医嘱、检查资质和有效工位均已准备。
**起始对象与终止状态：** 起始：医生持有原医疗工位；终止：检查结果独立保存、原医生恢复医疗接诊，或在条件不足时阻断。

| 步骤 | 承接岗位 | 流程动作 | 唯一功能用例 | 用户应观察 |
| --- | --- | --- | --- | --- |
| 1 | 治疗医生／前台 | 创建检查任务、保留原工位并报到派生任务 | [UAT-EXM-002](../../30-functions/clinical-exam/cases/UAT-EXM-002.md) | 保留及派生任务关联同一患者；此处执行步骤 1–5a，记录 RUN 后暂停，不重复实际到店。 |
| 2 | 检查医生 | 在检查工位启动已报到任务 | [UAT-QUE-001](../../30-functions/intake-queue/cases/UAT-QUE-001.md) | 队列中核任务编号和检查岗位；进入检查工作台后核患者。 |
| 3 | 检查医生 | 执行外部检查、确认结果并结束检查段 | [UAT-EXM-001](../../30-functions/clinical-exam/cases/UAT-EXM-001.md) | 记录实际检查与结果版本，检查段结束不代表医疗完成。 |
| 4 | 治疗医生 | 引用 QUE-001 和 EXM-001 原 RUN 后以步骤 5b、6–8 续办原工位返回 | [UAT-EXM-002](../../30-functions/clinical-exam/cases/UAT-EXM-002.md) | 原持有人确认真实返回后恢复医疗；不得再次开医嘱或重复前半。 |
| 5 | 治疗医生／授权文书负责人 | 按清单另备独立 A、B 验收；如场景03或07已完成，只读引用其原 RUN | [UAT-TRT-003](../../30-functions/clinical-exam/cases/UAT-TRT-003.md) | 已有 A、B 结果只读引用，不重新交还或完成；A、B 不是刚恢复的同一接诊；不能把检查结束视为完成，刚恢复接诊的后续须按负责人安排处理。 |

**一次性业务提交：** 医嘱发行、保留、任务报到、检查结果和恢复都是独立提交；EXM-002 前后是同一用例的接续。
**停止而非重放：** 原持有人缺席、保留过期、位置或任务不符、存在未解决执行、结果未知时停止；超时接续未具备安全条件则 BLOCKED。同工位检查当前缺口。已恢复的 SC04 接诊须先由负责人合法处理或使用不同医生、患者及工位，才能准备独立 A/B；不能因跳转而重复处理同一接诊。

每步只在对应功能用例执行并记录。已提交的同一业务来源不得重放；若需验收另一独立支线，按用例前置准备不同的新合成对象，可再次执行该用例并分别记录。场景引用已有结果时只接续或查看，不重复提交。若指定用例前置不足，记录 BLOCKED。

**结束与后续：** 达到上方终止状态后，可进入 [下一场景](../07-document-handover/README.md)，或返回 [场景与手册总入口](../../README.md) 选择支线。
