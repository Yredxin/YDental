# 医生交接及待完善文书接手

当前准备：**ENVIRONMENT_NOT_READY**。本页是流程导航；所有用户用例初始 NOT_RUN，用户结果只填写在各功能用例中。

**逻辑对象：** `SC07-EXEC-A`、`SC07-EXEC-B`。这些是未来分配的逻辑编号，并非数据库 ID；先按[合成对象映射](../../00-guide/scenario-data-map.md)由负责人核验实际对应与状态，再按[唯一执行清单](../../00-guide/execution-checklist.md)执行或接续。结果记录在唯一原始用例对应 RUN-ID；同一来源已执行动作只引用原记录，不重复提交。

**目的与价值：** 检验未完成的文书由合法负责人承接，并区分任务交还和正常完成。
**参与岗位与交接：** [治疗医生](../../10-roles/treatment-doctor/README.md) → [店长](../../10-roles/store-manager/README.md)。箭头表示主要协作，并非授权或严格身份切换；各步骤以其岗位为准。
**前置准备：** 若 SC07-EXEC-A/B 已在场景03或04完成，仅引用其原 RUN 并只读核验，不重复保存、交还、转派或完成；未执行时按唯一清单进行。

**其他前置：** 专用新合成接诊及未确认文书，合规文书负责人、权限和编辑租约状态已准备；不使用历史责任账号。
**起始对象与终止状态：** 起始：有责任但未确认的合成文书；终止：接续责任、版本与编辑状态可追溯，或注明阻断。

| 步骤 | 承接岗位 | 流程动作 | 唯一功能用例 | 用户应观察 |
| --- | --- | --- | --- | --- |
| 1 | 治疗医生 | 仅按用例保存合成文书，不执行文字确认 | [UAT-TRT-001](../../30-functions/clinical-exam/cases/UAT-TRT-001.md) | 观察自动保存及版本，保持 A 文书 pending 以供交还和接手。 |
| 2 | 治疗医生／授权文书负责人 | 用 A 和另备的独立 B 合成接诊分别核对交还、完成与文书责任 | [UAT-TRT-003](../../30-functions/clinical-exam/cases/UAT-TRT-003.md) | 释放编辑器后核对合法责任转派，保留原作者、版本和来源。 |

**一次性业务提交：** 保存、交还、完成、转派及补记可能持久化；实际治疗由 TRT-002 唯一负责，本场景不重复。
**停止而非重放：** 身份不符、租约未释放、责任未确认、提交未知，停止并由负责人核实，不覆盖原作者或旧版本。

每步只在对应功能用例执行并记录。已提交的同一业务来源不得重放；若需验收另一独立支线，按用例前置准备不同的新合成对象，可再次执行该用例并分别记录。场景引用已有结果时只接续或查看，不重复提交。若指定用例前置不足，记录 BLOCKED。

**结束与后续：** 达到上方终止状态后，可进入 [下一场景](../09-documents-reports/README.md)，或返回 [场景与手册总入口](../../README.md) 选择支线。
