# 问题汇总

每个问题分配全套私有副本中唯一的 `UAT-ISS-0001` 形式 ID；一个 RUN 可关联多个问题，也可由多个 RUN 引用同一问题。此处索引[原用例](../README.md)内的问题记录，保留发生位置、用例和 RUN、前置条件、首次实际步骤、预期与实际差异、复现步骤及稳定性、P0–P3、功能/UI/需求/环境分类、截图和是否阻断。不要在汇总中维护另一套互相冲突的实际事实。

疑似 P0（数据、资金、临床安全或严重权限）停止受影响操作并联系环境负责人。不能为了记录问题而重新执行已提交或结果未知的收费、治疗、库存或退款动作。
