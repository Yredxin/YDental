# 用户结果汇总

每次执行的原始事实保存在对应功能用例中的独立 RUN 记录；此目录是索引，不另写不同版本的实际结果。每个 RUN 可关联多个问题 ID，跨设备及复验均另开 RUN。空白代表尚未填写，阶段和最终结论初始 NOT_RUN，截图及填写材料默认保存在私有副本。

- [阶段完成登记](stage-status.md)：引用对应的用例及 RUN。
- [问题汇总](issues.md)：为每个问题分配 `UAT-ISS-0001` 等唯一 ID，链接原用例中的问题记录及 RUN。
- [UI/UX 意见](ui-feedback.md)：按 RUN 引用各页面和意见，独立于功能结果。
- [新增及变更需求](requirements-feedback.md)
- [修复后复验](retest-register.md)：以新 RUN 引用原问题和原 RUN。
- [最终用户结论](final-review.md)

使用说明参见[如何填写](../00-guide/how-to-use.md)；结果、等级与 UI 满意度参见[术语](../00-guide/terminology.md)。
