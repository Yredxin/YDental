## 阻断与待用户选择的路径

当前没有能确认已获授权的用户端访问方式和凭据私下交付渠道，按本工作包停止连接尝试；不能签署 `UAT_L1_READY`。请用户选择实际使用方式，并由环境负责人核实相应条件：

1. **项目主机本机操作**：用户直接使用项目主机上的浏览器；仍需确认用户能够实际操作该主机，以及通过获准私有渠道取得普通前台测试账号。
2. **已有获准的远程访问方式**：用户说明已获授权的既有方式，环境负责人核实其适用本次测试、用户设备可达及凭据可安全交付；不因 SSH 监听存在而推断授权。
3. **新增内网访问方式**：若确实需要新增网络配置，由用户先决定具体方案及授权范围；本轮不会自行变更防火墙、代理、认证、SSH 权限或监听范围。

选择后，环境负责人先按 [访问与受控启停说明](l1-access-and-startup.md) 核验合法通道、目标身份和安全凭据交付，再按已验证的受控流程启动。用户在自己的设备打开实际地址、登录，并确认明确显示的当前合成门店，随后只观察[首次体验路线](l1-first-session.md)中已核实的只读页面；不得提交治疗、发药、收费、退款、日结或文书确认。用户反馈实际可达情况、门店确认和页面结果时，不发送密码、Cookie 或 Session。

用户完成连接验证后，再依据实际证据裁定哪些 L1 只读步骤可开始；未核实门店、页面身份或内容的项目继续 BLOCKED。随后负责人正常停止指定服务，独立 Reviewer 核验停止状态，保留测试数据、账号责任及正常访问产生的审计。持续开放后续 UAT 须另行明确运行安排。
