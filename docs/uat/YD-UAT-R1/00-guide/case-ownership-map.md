## 使用及分工边界

- 对应 35 份用例中各步骤的写入所有权以用例正文为准；多角色场景只指向既有记录，不另行执行同一来源。
- TRT-001 文书自动保存会产生版本；保存和确认必须分开选择。TRT-003 使用两个不同接诊，EXM-002 跨医嘱、保留、检查、返回分段接续。
- 一次性动作遇到响应未知、旧页或结果与来源不符，停止受影响动作，由环境负责人核查后记录；不能换请求或新建来源补证。
- 用户不操作数据库；真实对象编号仅由环境负责人在准备完成后私下映射，逻辑 ID 不冒充数据库 ID。
