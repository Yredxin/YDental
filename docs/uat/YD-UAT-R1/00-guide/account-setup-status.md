# 合成测试账号设置记录

本轮复用独立 UAT scratch 中已有的十个普通合成账号，没有创建第二套账号。按 Odoo 正常密码修改向导，分别将十个账号设置为同一个测试密码；随后独立检查者使用新 HTTP 会话逐个登录，确认登录用户与相应私有 provider 对应，且指定门店的原有授权未变。管理员密码未改；店长任命仍为 `POLICY_PENDING`。

账号在[按账号验收导航](account-based-testing.md)中使用 A01—A10 逻辑标签：A01 前台、A02 治疗、A03 检查、A04 药房、A05 仓库、A06 收费、A07 财务审批、A08 复诊、A09 外加工、A10 报表。标签不是登录名。实际登录名及共同密码只在本机权限 `0600` 的私有清单中，未进入 Git 或本报告；待确认获准的私有渠道后交付，不能凭清单存在就认定用户已取得。

## 数据与证据范围

独立新连接在本轮前后核对 117 张受检表：用户、访问审计及访问会话的摘要发生变化，审计记录 **413→503**、会话记录 **99→129**；其余 114 张摘要一致。该比较仅限受检表，不能外推全库。密码修改向导及其行各由 11 增至 21，新旧行的暂存密码字段均为空；独立观察另产生一条无密码的空向导。以上是状态核查，不代表旧 Session 已失效。

两次观察各自的首次停止命令均返回 exit 1，原因分别为 **UNKNOWN**；各自经独立核实身份与连接后分别接续停止并返回 exit 0。修改密码一轮的唯一停止命令返回 exit 0，指定数据库容器 `exited`、`network none`，目标端口无监听；Odoo 退出码与 Session 失效仍为 **UNKNOWN**。未据此清理历史对象或停止其他实例。

本轮由账号设置执行者和未参与设置的 Reviewer 分工完成，二者共享项目主机，不代表操作系统隔离。私有原始凭据、会话及完整配置不进入公开仓库或聊天。

## 用户开始前的限制

Windows 实际访问及账号的私下交付仍未验证；原有数据库管理 URL 的验收边界尚待用户决定。本轮没有启用局域网监听，服务现已停止，不表示用户现在可以登录。按[局域网记录](l1-lan-access.md)核对后再确定下一次运行安排；不要将上次本机页面体验当作 Windows 验收。

十个账号的密码和登录核验不等于业务数据或功能均已准备。工位资格、库存、模拟会计和其他跨岗位来源等仍须按[环境状态](environment-readiness.md)逐项检查；49 个原用户用例结果仍为 `NOT_RUN`。P14-V2 T09 FAIL、历史 PARTIAL 与 UNKNOWN 保持，#37 保持 OPEN。
