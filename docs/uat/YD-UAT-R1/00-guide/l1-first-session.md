# L1 首次只读体验（本机验证范围）

**当前不能直接开始：服务已停止、用户设备访问及凭据安全交付尚未验证。** 本路线仅指页面的只读子步骤，不执行原用例中的完整业务流程；每个原用例的用户结果仍为 `NOT_RUN`，本路线某一步成功不能将整个原用例标为 PASS。下表 READY 仅指本机对应账号 GET 200、最终路径正确且全页文本包含合成门店名称，不证明名称位于 Current store 或主区内容正确；本轮切换唯一已授权门店返回 303。用户须自行找到明确的 Current store 和页面标题，对不上或无法判断就停止。EMPTY_BUT_READABLE 需要目标区域的空态证据；BLOCKED 为未获足够证据或前置缺失。服务已停止，这些状态不是用户端准出。运行前由环境负责人按[访问和启动说明](l1-access-and-startup.md)重新核版本、目标与状态，并私下提供获准的登录方式、账号和测试对象；不在本文件填写账号或密码。

普通登录与选择已授权门店可能产生正常认证及读取审计。进入页面后只查看，不点击任何创建、保存、叫号、报到、治疗、处方、检查确认、发药、出账、收退款、日结、原件生成、导出或打印按钮；不要提交表单。若门店不符、出现权限错误或内容不明，停止并记下实际情况，交环境负责人核实，不换身份绕过。医疗工作台本轮返回 422，保持 BLOCKED。两轮测试各有六个技术性 POST 被测试工具本地预拦截，此为预拦截而非产品拒绝；因此本轮不能外推完整浏览器交互均已验证。

## 记录与暂停

每个原用例可复制其用户填写区，用新的 RUN-ID 记录“只读子步骤”、日期、环境、岗位门店、浏览器和视口、观察以及截图路径；整个原用例仍保留 NOT_RUN。一个 RUN 可关联多个问题；不要通过重做任何一次性提交来复现。截图及填写后的副本只保存在私有位置，避免包含账号、密码、Session、真实患者及未经授权的临床或财务信息。只读展示与空态的准备状态以[环境报告](environment-readiness.md)为准；经实际用户设备连接验证并确认服务在运行前，`USER_ACCESS_UNVERIFIED` 和 `UAT_L1_READY` 未满足。
