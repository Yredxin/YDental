# UAT-FIN-006｜线下收款渠道更正

- 所属阶段：U05；层级 L2；参与岗位：具本店权限的收费员。
- 真实权限：当前店 settlement write、公司范围；合成会计策略的原/新渠道清算账户必须不同且属于同公司。
- 需求／技术阶段：R21；S10-T01–16；准备状态 DATA_NOT_READY。

## 作用与核心行为

对一次已记录的合成线下收款更正分类，观察来源和金额；不发生真实资金流。

## 页面与前置

`/ydental/settlement` 的线下付款与退款。使用专为此例准备、未更正的独立合成收款，其原/目标渠道同一业务日未锁日结；负责人确认两个渠道、相应合成日记账和不同清算账户，以及唯一收款记录。账户配置不具备或来源不唯一则 BLOCKED。

## 操作与预期

| 步骤 | 用户操作 | 可观察结果 |
|---|---|---|
| 1 | 找到唯一合成收款，记录显示的原收款编号、金额和原渠道。 | 与预备表一致；错误或已更正则停止。 |
| 2 | 展开该收款“Correct collection channel”，选择不同的合成目标方式，填写更正原因。 | 目标方式、理由与负责人预备表一致。 |
| 3 | 点击“原生重分类更正”一次。 | 提交结果不明确即停止、由负责人核实，不重复点击。 |
| 4 | 查看该收款行及其 Source trace；由负责人通过合法来源核实更正记录、原收款和金额。 | 原收款及金额保留；应有单次更正记录。页面行显示的是原渠道，不能以该标签变更作为通过条件；未能核实则 PARTIAL。 |


## 异常、一次性提交及停止条件

只使用独立的新合成来源；相应动作产生持久记录。缺权限、对象、资格或合法配置时标记 BLOCKED，不借历史对象或改变规则。响应未知时立即停止，由负责人核查该原来源和结果，不重复提交；P0 停止受影响操作。实际用户结果初始 NOT_RUN。

## 结束条件与后续

登记本次 RUN 和可见结果；后续业务须以该来源的实际状态为前置，不重复生成相同来源。
