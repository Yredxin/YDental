# UAT-EXM-004｜合成检查部分完成

- 所属阶段：U05；层级 L3；参与岗位：检查医生及接续医疗医生。
- 真实权限：当前店 exam write、合法检查任务和本人持有的 serving 检查工位，精确能力和项目所需有效资质。
- 需求与技术阶段：R18；S09-T05/06；准备状态 DATA_NOT_READY。

## 作用和核心行为

用另一条独立检查医嘱记录先实际执行、后部分完成的事实，保留实际费库来源和结果责任。

## 页面与前置

检查医生使用原持有工位连接的同一浏览器、同一标签页进入 `/ydental/exam`；连接缺失则停止，不得新造或借用。前台已对新合成检查任务报到，检查医生已叫号并开始实际执行；对应检查行未曾实际执行，模板、资格、价源及可用批次已由负责人核定。与 EXM-001/003 分用不同医嘱行；不能以历史结果作来源。

## 操作与预期

| 步骤 | 用户操作 | 可观察结果 |
|---|---|---|
| 1 | 找到对应合成患者和冻结医嘱行，核对任务号和无已有真实执行。 | 任务、患者、医嘱一致；已有执行或状态不明则停止。 |
| 2 | 填写模拟所见，未测量字段标未知，保存独立结果草稿。 | 草稿可见；点击“查看独立结果与版本”，在新标签原始 JSON 中读取 version 后返回工作台。未知测量没有伪造数值。 |
| 3 | 填写模拟实施说明及所需合成耗材，点击“确认真实执行一次并取价”。 | 当前行显示真实执行人、费源及其状态；状态或来源不明停止不重发。 |
| 4 | 填写合成“实际中止/部分完成原因”，点击“记录实际中止或部分完成”。 | 已存在实际执行时，结果及医嘱行为部分完成；若没有执行事实则源码将记作中止，本用例不应把它当部分完成。 |
| 5 | 记录当前结果与费源状态；在负责人确认无未解决费库后填写结束说明，点击“结束检查段并释放工位”。 | 外部检查段结束；结果为部分完成的事实保留。出现待核对、版本冲突或状态不明时停止，由负责人核实而不重做。 |


## 异常、一次性提交及停止条件

只使用独立的新合成来源；相应动作产生持久记录。缺权限、对象、资格或合法配置时标记 BLOCKED，不借历史对象或改变规则。响应未知时立即停止，由负责人核查该原来源和结果，不重复提交；P0 停止受影响操作。实际用户结果初始 NOT_RUN。

## 结束条件与后续

登记本次 RUN 和可见结果；后续业务须以该来源的实际状态为前置，不重复生成相同来源。
