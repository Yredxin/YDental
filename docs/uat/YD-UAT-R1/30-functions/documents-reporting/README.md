# 文书原件、报表和导出

当前验收环境为 ENVIRONMENT_NOT_READY；所有用例默认 NOT_RUN。先准备独立合成来源及真实授权；技术测试不代替用户验收。

| 用例 | 内容 | 主要依赖 |
| --- | --- | --- |
| [UAT-DOC-001](cases/UAT-DOC-001.md) | 预览、生成与读取文书原件 | 已确认合成文书 |
| [UAT-DOC-002](cases/UAT-DOC-002.md) | 对保存原件请求打印 | DOC-001 原件 |
| [UAT-RPT-001](cases/UAT-RPT-001.md) | 授权报表及回源 | FIN-002 合成收款 |
| [UAT-RPT-002](cases/UAT-RPT-002.md) | 导出报表与审计证据 | RPT-001、export write |

来源权限与 export 权限分开；打印请求不代表实际出纸。正式签署、真实税票、设备和外部传输未授权；全局审计用户入口未固定，审计仅在负责人提供合法独立证据时审阅。原件生成是持久提交，不复用历史对象或盲重试。
