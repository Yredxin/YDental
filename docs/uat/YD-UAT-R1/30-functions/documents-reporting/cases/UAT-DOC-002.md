# UAT-DOC-002｜请求打印已保存的合成原件

- 所属阶段：U06
- 参与岗位：有来源读取权限的文书使用者
- 真实权限要求：当前门店原件对应来源读取权限，例如临床原件 medical read 或更高，且患者与公司范围有效；此打印请求不等于批量导出权限。
- 对应需求／技术阶段及 TC：R24；S08-T11、S12-T01、T05
- 验收层级：L2
- 当前可验收准备状态：ENVIRONMENT_NOT_READY；步骤依据 SOURCE，环境、账号、数据准备后方可验收。

## 业务作用与核心行为

检查系统对已保存原件发起打印请求的入口和返回；不证明物理出纸。

## 页面与前置条件

打开 `/ydental/documents`；UAT-DOC-001 已在本独立环境生成唯一可识别的合成临床原件，备有患者编号、原件编号及版本。只使用浏览器PDF处理，不连接真实设备；若无法唯一识别则 BLOCKED。

## 有序操作和预期结果

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 以有权账号进入当前合成门店，搜索合成患者。 | Saved originals 列出已准备的原件。 |
| 2 | 核对患者、类型、原件版本及生成UTC时间；展开 Source, template and file trace 核对原件内部编号。 | 四项与准备记录一致，不能确认则停止。 |
| 3 | 在该原件行展开 Request printing。 | 页面明确显示请求不代表已验证物理出纸。 |
| 4 | 点击 Request printing original 一次。 | 浏览器新标签接收原件PDF；记录是否可打开，不推断纸张输出。 |
| 5 | 返回原件列表，核对患者、原件版本仍与步骤2一致。 | 原件版本仍可辨识；如PDF未返回或权限错误则停止并记录。 |

## 异常与权限负例

无该来源权限或切到无权门店不得读取该原件；只使用独立测试账号，无法安全确认状态则 BLOCKED。

## 一次性提交及停止条件

打印请求会记录审计，结果不明不盲目重试；不选择真实打印设备、不上传PDF。纸张、税票和正式签署均未授权。

## 结束条件及后续衔接

完成页面及PDF返回观察后进入 UAT-RPT-001；不把请求成功写成出纸成功。
