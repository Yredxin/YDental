# UAT-LAB-003｜已入库合成工单的免费返工

- 所属阶段：U06；参与岗位：治疗医生与仓库负责人；层级 L3。
- 真实权限：同一当前店 medical write 与 warehouse write、允许公司范围及原生工单模型权限；有效供应商与合作资格。
- 对应需求／技术阶段及 TC：R23；S11-T13–18。
- 当前可验收准备状态：DATA_NOT_READY；仅源码证据，尚未运行或用户验收。

## 业务作用与核心行为

对未戴用、已实际入库的合成工单登记免费返工，观察原工单退回、库存事件和新返工周期，避免将其当成普通工单状态编辑。

## 页面与前置条件

进入 Dental Laboratory → Work orders。先按 UAT-LAB-002 为本例独立合成对象完成发出、回货及入库，原工单必须 available、实际批次可辨认且未戴用；记录原 RUN 和工单唯一标识。工单已戴用、已返工、来源无法定位或供应商资格不成立时 BLOCKED。该工单不可同时用于 UAT-LAB-004 戴用支线。仅模拟处理，不发送真实包裹或外部通知。

## 有序操作和预期结果

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 有权人员打开已定位的独立合成 Work order，核对状态、患者、商品和批次。 | 状态 available，来源与原 RUN 一致；未找到时停止。 |
| 2 | 在 Rework and disposition 中选择免费返工，填写合成返工原因并保存。 | 保存是持久写；保存后所选返工类型与原因可见。结果不明时停止并由负责人先核状态，不盲目重复保存。 |
| 3 | 点击 Return for rework 一次。 | 原工单状态转为 rework_returned；事件列表出现返工退回及关联库存事件，并创建一个 draft 返工子工单。 |
| 4 | 刷新并查看原工单的事件和关联返工工单。 | 可定位一个关联 draft 子工单及返工号；原患者与治疗来源保持关联。无法唯一辨认时停止并联系负责人。 |

## 异常与权限负例

未入库、已戴用、缺少 warehouse write 或无返工原因不得完成；只在独立合成负例且负责人能核查前后状态时测试。后续收费或采购政策不在本例确认。

## 一次性提交及停止条件

第2步保存返工类型和原因是持久写，结果不明先核工单已保存内容，不盲目重试；第3步同时产生真实库存退回与子工单，是一次性持久提交。响应未知先核状态、库存事件及子工单；不要再次点击或重新入库。发现多条来源、库存或权限异常时停止。

## 结束条件及后续衔接

原单 rework_returned 与唯一子工单 draft 可读后结束。后续处理新返工周期前另行核定采购及费用前置；不向真实供应商发货。
