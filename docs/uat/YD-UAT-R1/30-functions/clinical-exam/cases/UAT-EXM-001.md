# UAT-EXM-001｜检查实际执行及独立结果

- 所属阶段：U05
- 参与岗位：检查医生（本例仅覆盖外部检查工位）
- 真实权限要求：exam write；当前门店真实检查任务及有效工位连接、准确检查能力和所需未撤销有效资质；本例不覆盖同工位医疗内检查。只读查看有自身来源和权限限制。
- 对应需求／技术阶段及TC：R13、R18、R24；S09-T02/03/04/05/06/07/10/13
- 验收层级：L3
- 当前可验收准备状态：ENVIRONMENT_NOT_READY；仅源码支持的拟验步骤，未部署、未实测、用户 NOT_RUN。

## 业务作用与核心行为

记录一次检查事实及独立结果，区分真实执行、结果文字确认和检查段结束。

## 页面与前置条件

UAT-EXM-002 前半已开具本次新合成检查医嘱并冻结；由前台报到及 UAT-QUE-001 启动对应检查任务。负责人已准备审定的演示检查模板绑定、准确能力、人员有效资质、价源和必要合成耗材。当前检查工作台 `/ydental/exam` 中同一行患者、冻结医嘱及任务匹配；不满足则 BLOCKED。

## 有序操作和预期结果

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 打开检查工作台，找到本次患者和冻结医嘱行。 | 行中患者、医嘱、任务、项目方向与准备清单一致；不同则停止。 |
| 2 | 查看本行状态、真实执行和结果状态。 | 确认没有已存在真实执行；若已有来源，不得重复执行。 |
| 3 | 填写模拟所见，按实际合成检查选择测量状态或未知，点击 保存独立结果草稿 一次。 | 结果草稿可见；点击 查看独立结果与版本 在新标签打开原始 JSON，查看 version 字段后返回原工作台；必要时请环境负责人协助。未知不能填写为已测量。 |
| 4 | 填写 实际实施说明；若模板要求耗材，选择实际合成批次和数量。 | 内容与授权模拟清单相符；耗材和价源不明时停止。 |
| 5 | 点击 确认真实执行一次并取价 一次并确认。 | 本行显示真实执行者、费用来源和费源状态；若待核对则记录，不冒账务已完成。 |
| 6 | 填写人工结果审核说明，点击 确认结果文字（不代表正式签发） 一次。 | 结果状态为已确认；点击 查看独立结果与版本，在新标签原始 JSON 中核对 version 增加并返回原工作台；必要时请环境负责人协助。仅当有实际执行及非空所见才能确认，并不代表正式签发。 |
| 7 | 填写结束检查段说明，点击 结束检查段并释放工位 一次。 | 检查段结束；检查结果确认与工位段结束分别记录。若结果待核对或未解决则停止并保留事实。 |
| 8 | 将结果行及患者返回信息交给原医疗岗位。 | 结果可由有权限人员按来源查阅；患者返回处理由 UAT-EXM-002 后半执行。 |

## 异常与权限负例

能力或人员资质不足、检查来源与患者不符、旧版本或费库未解决应拒绝；不伪造资质或补做真实检查。同工位检查另需源医疗接诊及精确能力；该路径的结束结果为 medical_continues，不释放医疗工位，本例未覆盖并应作为缺口记录。

## 一次性提交和停止条件

草稿、执行、确认和结束均提交。真实执行会生成不可重放费库来源；响应未知先核该行状态及来源，不能再点执行。

P0 数据、资金、临床安全或严重越权异常应停止受影响操作，保留事实并联系负责人；未确认提交时不重试。

## 结束条件及后续衔接

单次执行、结果版本和检查段结束各自可见；进入 UAT-EXM-002 的返回步骤。
