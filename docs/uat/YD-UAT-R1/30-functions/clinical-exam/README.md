文书文字确认、实际治疗、检查执行、检查结果确认、检查段结束、医疗接诊交还和正常完成是不同动作。响应未知先核状态，不得重放；正式临床签署和真实业务不在本手册生产授权内。

同工位医疗内检查不在本组已编步骤中：其结束保留医疗接诊继续，不等于释放医疗工位，待补充独立用例和审查。
