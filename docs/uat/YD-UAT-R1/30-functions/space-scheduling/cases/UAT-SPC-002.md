# UAT-SPC-002｜公共与门店空间资源

- 所属阶段：U01
- 参与岗位：集团资源管理员、门店空间配置人员
- 真实权限要求：门店资源需当前门店 space=write；公共资源需集团管理员身份及有效内部会话，不能以门店 space=write 推断公共资源写权；查阅范围按授权。
- 对应需求／阶段／TC：R06；S02-T01–10
- 验收层级：L2
- 当前可验收准备状态：**ENVIRONMENT_NOT_READY**；须由环境负责人核实固定候选、账号及数据后再执行。用户结果初始为 NOT_RUN。

## 业务作用与核心行为

管理牙椅、门、候诊标识等空间图形资源，区分集团共享和门店私有。

## 入口、前置条件

YDental → Clinic space → Resource library；表单包括 Store、Workstation or artwork type、Capabilities、Upload SVG 和 Safe SVG source。

测试门店和空间管理员已准备。环境负责人提供无敏感信息、符合系统安全限制的测试 SVG 文件，以及允许使用的测试名称；集团公共资源仅在另有集团管理员账号时测试。

## 操作及逐步预期

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 进入 Resource library，查阅资源列表并记录当前门店。 | 可见的资源属于该门店或允许读取的公共资源；不推断列表涵盖其他门店。 |
| 2 | 新建门店资源，填写名称、当前 Store、图形类型，并选择准备好的安全 SVG 上传。 | 表单提供对应字段；上传仅为本次测试素材。 |
| 3 | 保存后重新打开刚创建的门店资源。 | 名称、门店和类型与输入一致；系统保留净化后的 SVG，不要求原始上传文件仍存在。 |
| 4 | 如已提供授权的集团管理员身份，在同一测试环境新建一条 Store 留空的公共测试资源。 | 集团账号可保存该公共资源；普通门店写账号不能据此获得公共资源写权。未准备该身份时此步记为未执行。 |
| 5 | 用仅门店权限的另一个测试账号查看授权内资源。 | 门店账号可查看授权范围内共享资源；公共资源更改不应获得仅凭门店 space=write 的授权。 |

## 异常、权限负例和停止条件

仅对新合成资源测试权限拒绝；不上传真实平面或患者图像。非法 SVG 可被拒绝或净化，实际行为逐项记录，不能据此外推所有格式。

每次资源保存是持久提交，公共资源影响共享范围；仅在事先批准的测试环境创建。结果未知先查询，不重复新建。

## 结束及衔接

门店资源可重查，公共资源步骤按权限记录完成或保留未执行。

平面配置见 [UAT-SPC-001](UAT-SPC-001.md)。
