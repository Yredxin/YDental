# UAT-LAB-001｜查看供应商资质与门店合作

- 所属阶段：U06
- 参与岗位：集团管理、仓库负责人
- 真实权限要求：查看资质菜单及审批需集团管理组和允许公司范围；合作记录当前门店 warehouse read，改变合作需 warehouse write。岗位名称不自动授予权限。
- 对应需求／技术阶段及适用 TC：R23；S11-T13–16
- 验收层级：L2
- 当前可验收准备状态：ENVIRONMENT_NOT_READY；下述为源码依据，尚未实际部署或用户验收。

## 业务作用与核心行为

核对合作供应商资质及门店合作是否满足外加工工单的使用条件。

## 页面与前置条件

在 Dental Laboratory → Vendor qualifications 和 Store cooperation。环境负责人提供同公司、合成供应商及已准备的资质文件、未来有效期和门店合作记录；不得上传真实证件或外部资料。审批由有组权限人员执行，合作由有 warehouse 权限人员执行。若菜单或合成资格不具备则 BLOCKED。

## 有序操作和预期结果

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 集团管理人员打开 Vendor qualifications，按合成名称找到唯一供应商。 | 列表显示供应商、资质参考、有效期和状态；公司在授权范围内。 |
| 2 | 打开记录，核对资质参考、有效期、公司和审批资料。 | 所有内容属于合成供应商，有未来有效期；资料缺失则停止。 |
| 3 | 若该合成记录为 draft 且按测试安排应审批，填写合成 review reason，点击 Approve qualification 一次。 | 状态显示 approved，查看 reviewed by 和 reviewed at；已 approved 时跳过审批，不重复点击。 |
| 4 | 仓库负责人在当前合成店打开 Store cooperation，选择该供应商记录。 | 可见供应商、Active、local reference 和负责人；若记录已归档，使用 Archived 筛选同一记录，找不到则 BLOCKED；确认 Active 状态。 |
| 5 | 如记录未启用且环境负责人指定本合成记录可启用，点击 Enable / disable cooperation 一次。 | Active 从未启用变为启用；原已启用时跳过，不要来回切换。 |

## 异常与权限负例

无集团管理组不应取得资质审批入口；warehouse read 不应执行合作更改；过期资质、缺证明或跨公司不可作为发单条件。负例必须使用独立合成记录且前后可核。

## 一次性提交及停止条件

审批和合作切换会持久写入及审计。状态不明先重新读取该记录；不能确认则停止，不连点或覆盖历史资质。 出现数据或严重权限异常，停止受影响操作并登记。

## 结束条件及后续衔接

批准且当前门店合作启用后，按 UAT-LAB-002 准备新合成工单；过期／权限缺失则 BLOCKED。
