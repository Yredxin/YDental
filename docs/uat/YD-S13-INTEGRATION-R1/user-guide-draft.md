# 牙科门诊岗位操作指南（整改草稿）

本指南仍在随集成整改验证，**尚未准备用于用户验收**。服务入口、体验窗口、岗位账号和新的合成场景须在交付前另行确认；不要使用开发预验已办理过的患者和业务。本指南只描述合成门店，不适用于真实患者或真实支付。

## 开始办理

使用分配给自己岗位的账号登录，在牙科首页核对当前门店、岗位能力及页面显示的工作入口。各岗位待办覆盖仍在验证。换岗时先退出，再用对应账号登录并核对门店。首页没有预期入口，或页面提示没有资格、工位、供给、价格或库存时，请按提示交给有权岗位处理；不要猜测地址或借用其他人的账号。部分队列选项仍显示内部任务编号，正在整改。

## 前台与医生

1. 前台从首页进入患者工作，建立新的合成患者或选中正确患者，再进入受理。预约按可用区域、能力和时段选择；现场办理按页面的现场受理流程选择。预约不预先指定医生。
2. 实际到店后记录到店，再对需要办理的任务报到；这两个动作分别完成。确认患者及任务出现在相应队列后，交给医生。
3. 医生从首页查看当天安排和队列，进入具有相应资格的工位，叫号并接诊。打开当前接诊的文书，保存草稿和确认文书是不同动作；保存草稿不会代替实际治疗。
4. 按医嘱实际执行需要的治疗，核对执行状态与费用。完成接诊和确认文书分别办理；接诊结束后仍有待确认文书时，由责任岗位继续处理。

## 检查和药房

1. 医生在当前接诊开立检查，按业务需要选择保留工位或保存并交还。前台对派生的检查任务报到；检查岗位进入相应工位、叫号、执行并记录结果。
2. 保留工位的患者按原有规则直返；尚未返回的保留段不能直接交还。交还后的后续接诊由前台报到并按资格重新分配；目前浏览器只验证了原医生重领，跨医生情形仍待验证。确认结果回到正确的患者和来源后，医生继续办理。
3. 医生签署处方后，前台对药房任务报到；药房岗位叫号并按实际领取数量发药。分次领取时，每次只办理本次实际数量，并核对剩余数量。缺货后的恢复路径仍待普通岗位浏览器预验。

## 费用、收款和退款

收费岗位从首页进入待结算工作，选中正确患者，核对实际治疗、检查和发药产生的费用后出账。按实际合成收款逐笔登记，核对账单余额；付款金额和实际余额以页面为准。

需要退款时，收费岗位从相应收款发起申请，另一名有权人员审批，再由有权岗位登记实际退款。审批本身不等于退款完成；退款也不会自动退药。退药及库存恢复的独立办理路径仍待预验。

## 办理中断

如果提交后结果不明确，保留原页面，不要重复提交。页面提供本次操作核验入口时，先在原页使用；未命中或请求可能仍在处理时，结果仍为未知，请有权人员核查。关闭页面或标签可能丢失本次核验所需的临时信息，不能保证之后仍能执行同样的核验。

遇到工位过期或要求现场核实的接诊，只能由能够确认实际现场情况且有权的人员处理；不能为了继续测试而替他人确认。无法确认的情况保留原状并记录给技术团队。

## 其他岗位

复诊、外加工、文书原件与报表的入口、数据和跨岗路径仍在技术预验中，不能据此安排用户办理；完成验证后补充本节。原 49 项用户验收结果由用户实际办理后填写，团队的技术预验不代填。
