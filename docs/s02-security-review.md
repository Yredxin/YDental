# S02 安全复核

范围：本批 `ydental_space`、隔离验证工具与 `ydental_space_test`；使用 odoo-security 和对应后端/前端 house rules 自查。最终实测提交及结果见 [交付报告](s02-report.md)。这不是独立第三方复核或用户验收。

|检查面|实际处理与验证|边界|
|---|---|---|
|ACL、公司、门店、真实登录|五个实体均有原生公司限制；空间实体继承 S01 source；公共/私有资源独立动态域与显式 check_access；每次源读取和写入重新检查登录范围|T04 模型、真实 HTTP、浏览器；复用已收口 S01，不重做 S01|
|公共资源|集团维护权 + 当前店 space=write；普通用户只能读；私有仍限定本店|T10 集团正向/普通反向；切店后私有 SVG 403|
|公开 RPC/导出|snapshot、plan、save_geometry、归档均先鉴权；固定模型与几何字段白名单；派生字段和系统元数据不可写；能力关系只能关联现有字典；导出另需 export=write|无任意模型或方法调度；不接受客户端声称的占用或门店绑定|
|sudo|用于已授权记录的约束关联、公共定义的反向引用锁和保护钩子、派生楼层版本、固定配置读取、不可改审计写入、能力 ID 存在性检查|不向客户端返回越权源数据；跨店公共定义保护检查仅返回通用拒绝；SVG HTTP 不 sudo|
|SQL|仅 advisory/行锁；值参数化；表名来自模型 `_table` 并经 SQL.identifier|无原生 SQL 业务写入、字符串拼接输入或绕过 ORM 权限|
|并发与事务|真实登录范围锁 → 配置 advisory lock → 排序楼层/对象行锁；写时比较页面原版本；savepoint 保证批量几何全回滚；公共定义与摆放共用锁|两真实 HTTP 事务只一成功；不将此称为 S13 压测；未来任务创建须共用锁并重查|
|SVG/XML|有界 Base64 与字节数、安全 lxml 解析、禁实体/网络/DTD、节点/文本限额、元素与属性白名单重建、有限 viewBox/尺寸；原上传不存储|11 类攻击矩阵及文件输入负例；合法文件通过原生表单上传|
|XSS 与文件|SVG 使用鉴权 image 响应，CSP sandbox/default-src none、nosniff/no-store；没有 t-raw、Markup、innerHTML 或 eval；不提供任意文件路径读取|S01 protected source 集合注册全部五模型，public attachment 仍需源授权|
|前端生命周期|组件自身模板持有事件；销毁时由 Owl 清理；无全局订阅、定时器；局部 FormRecord 追加显示版本，不 patch 核心|真实 Firefox 无 JS 错误；无模拟实时颜色或状态|
|隔离运行|仅新 S02 合成库；集群/端点/OID/配置摘要核对；精确 dbfilter；独立 data_dir/log/端口；SMTP 黑洞、无 cron、进程外发限制；互斥 runner|5 项反向隔离测试；不接管历史库，不安装依赖或停止旧服务|
|证据与凭据|仅虚拟摘要、哈希、合成截图入库；密码随机保存在本机0600文件；截图前检查可见页面、密码输入及敏感值|原始日志、请求凭据、cookie/token、数据库备份不发布|

本批无未处理的已发现安全阻断。真实排期、有效任务、患者队列与租约尚未安装，保护只以合成服务端标记验证；这些联调明确 NOT_RUN，留 S03/S06，不用本批测试冒充真实业务保护。
