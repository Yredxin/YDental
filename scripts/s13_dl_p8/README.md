# DL-P8 bounded verification tools

Scope: the user-enabled YD-S13-DL-P8 / 1.0 plan. The completed stage is stopped;
these files do not enable a new service, a new phase or production. Do not reuse
an expired scope, an old run ID, a session cookie, or change a guard to replay it.

The actual product/runtime candidate is
`bd8411d4ef50014caddff7128f0c9cf4fe42f122`. The sole existing synthetic target,
its original filestore and pinned Odoo core are checked by the stage adapters.
Normal project providers remain private and ignored; no credential belongs in a
command, report or public artifact.

- `source_contracts.py` restores only the 25 allowed presentation nodes and
  compares the complete baseline XML; it also checks frozen business, selector
  JavaScript, inventory XML and original icon/license files.
- `test_runtime.py` ran 14 SOURCE/PURE checks, including read-operation matching
  and rejection of business writes. Mock sessions never make network requests;
  this is not business execution evidence.
- `runtime_config.py`, `admission_probe.py`, `bind_admission.py` and `launcher.py`
  bind a current candidate, genuine target/privileges, a fresh project scope and
  an actual non-implementer review. They retain the existing process-birth,
  dirty-tree, scope, ownership and stop checks. Earlier stage records are not
  modified. A rebind archives old bytes and never extends expiry.
- `protected_snapshot.py` performs complete read-only/RR snapshots with rollback
  and connection closure. A necessary load uses an explicit quiescent freeze
  and full immediate pre snapshot; `run_checks.py` allows only `ydental_print`.
  Exactly one print update ran. Pure asset changes used fresh registry manifest
  loading and actual CSS bundle/computed evidence without another `-u`.
- `http_client.py` permits only original GETs, normal authentication/store
  selection, and matching `preview`, `pdf_view`, `download` read POSTs. It
  refuses generate/printing/template/export/stock/scan business writes.
- `browser_checks.py` / `.cjs` are finite preparation drivers using real pinned
  Chromium and WebKit and normal authorized roles. No browser starts without
  the exact owned service. Each run archives its executed source/dependencies,
  argv, actual process exit and original uniquely named PNGs. Read bodies are
  finite; native download bytes and a separately labelled ordinary HTTP read
  are distinguished from a PDF viewer shell.

The actual 27 clients did not all execute the final generic file unchanged.
Finite, scoped private variants repaired inherited-table/submitter locators,
serialization representation, native viewport captures, no-JS waits, component
range/clip checks and finite file tails. Their exact sources and dependencies
are retained in `.local/dl-p8/testing/evidence/process-<label>/`; the full index
is `testing/client-index-final-v1.json`. Do not reconstruct an old source from
the current driver or call a failed client successful because some assertions
passed. One WebKit main client returned 130 after a controlled read-body wait;
its browser closed with exit0. Its 21 independently verified UI assertions are
reused explicitly, and a separate native download tail supplies actual bytes.
Chrome native200 white captures are preserved and replaced only as visual
proof by three separately recorded genuine CDP viewport captures.

P8's shared style source is a pure mixin in `ydental_access`; its manifest
registers it before the callers. Local `@import` is not used. P1 product JS and
all original form contracts remain frozen. Real busy observations are passive
trusted-submit observations; reset/pageshow/cancel are separately labelled
memory components. No request interception is passed off as product rejection.
