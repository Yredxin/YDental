# P12 settlement read-only presentation verification

Only the user-enabled `YD-S13-DL-P12 / 1.0` scope is covered. The root agent
owns product files, reports and runtime scheduling. These clients do not start a
service or create persistent business samples. A fresh independently reviewed
admission and the exact owned run are required before authentication.

`browser_checks.py` records the actual candidate, command, executed sources,
native log and child exit without automatic retry. `browser_checks.cjs` uses the
existing normal-role provider and browser dependencies. Normal authentication
and authorized store selection are followed by GET reads, original native
disclosures and original cancellation links. Business POST, PDF/original and
CSV paths are guarded; an interception is never a product permission denial.

Modes:

- `layout`: ordinary menu, q-only search by Enter, explicit patient link, five
  viewports, all three fee regions, trace, other-store GET, original operation
  expansion/cancel, safe empty query and name search.
- `zoom`: real engine native 200% with root 16px, separately root-font 200%
  with native 100%. The existing extension/WebKit native bridge is reused.
- `nojs`: normal CSRF/password authentication in the same JS-disabled context,
  native GET/link/details/keyboard. Sessions are never copied from JS contexts.
- `permissions`: actual backend responses for the normal provider role and
  explicit invalid/out-of-scope input. No temporary permission grants.
- `bypass`: limited original inventory, documents, reports/source, patient
  directory or settlement error page, retaining exact DOM/computed data.
- `components`: four explicitly marked loaded-QWeb memory components, with
  actual product CSS, empty/pending/pagination/long-text paths, five viewports,
  long-value zooms, text endpoints, native keyboard and missing CSS/SVG faults.
  Fixture identities, amounts and pagination do not prove real business data.
- `keyboard`: continuous trusted Tab/Shift+Tab from the original q field at
  320px, with native geometry retained and keyboard-only reach recovery.
- `states`: actual available action families. When the real page has no
  secondary pagination controls, the explicit paged component supplies that
  family; do not describe it as a real multipage business sample.
- `events`: trusted icon/text/empty-padding clicks on the actual Search and
  other-store links, plus text/padding on original undecorated candidates. Each
  actual action records one original GET and the original composed event path.
  Secondary pagination is tested separately in the explicitly loaded component,
  with trusted events and preventDefault, without claiming a successful HTTP GET.

`browser_settlement.cjs` preserves original form/URL/fee/currency/trace values,
and the complete rendered prefix and write suffix with computed styles.
Native CSRF/key/revision bindings are privately redacted by exact field name;
native `actual_utc` defaults and report `query_at_utc` are explicitly classified
and retained separately. Layout box/computed values are measured separately
from frozen semantics. There is no broad time, sort or amount normalization.

The isolated-target reach helper records native immediate/settled observations
before ordinary scroll observation. Its helper result is not a claim of native
Tab automatic full visibility. The continuous-keyboard mode uses no target
scroll helper, retains trusted input and any directional recovery, and fails if
the final original target remains clipped. AX snapshots do not prove a real
screen reader, OS IME, Safari/iOS or physical device result.

`viewing_package.py` builds an exclusive 0400 private ZIP from an explicit list
of original PNG source bytes and finite measurements. It includes no provider,
Cookie/profile, request body, full database, original PDF, program or font.
Every image/member/privacy assertion requires a separate non-implementer review.
The constructor's PENDING status is preserved in the original package bytes.

SOURCE checks and successful construction are not browser execution, business
acceptance, independent physical preservation, or a completed P12 delivery.
